# Fundo do login

cinema-mosaic.webp é um fundo original gerado para o login do VeloxPlay, inspirado nas referências fornecidas pelo usuário. Contém artes cinematográficas fictícias em mosaico, sem textos ou elementos de interface.

O arquivo foi convertido de PNG para WebP para reduzir o peso, mantendo suas dimensões. O formulário, as marcas e os controles são componentes HTML/Angular sobrepostos à imagem.
