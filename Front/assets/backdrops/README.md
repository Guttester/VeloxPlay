# Imagem de fundo de Interestelar

`interstellar.jpg`: 2880 × 1800 pixels, usada no banner e nos detalhes do filme.

Fonte: [WallpapersWide — Interstellar Movie Endurance Mission](https://wallpaperswide.com/interstellar_movie_endurance_mission-wallpapers.html).
Arquivo original: https://wallpaperswide.com/download/interstellar_movie_endurance_mission-wallpaper-2880x1800.jpg

A capa original de 320 × 500 permanece nos cards. Para usar esta imagem no banner,
cadastre `/assets/backdrops/interstellar.jpg` no campo de imagem de fundo do filme.
O início consulta `urlBackdrop` retornado pela API. Quando vazio, mantém a capa.
Não há associação automática por título, ID ou nome da capa.
